# EV Purchase Advisor Roadmap

## MVP (v0.1) - Initial Release
- [x] Pure Python Calculation Engine (TCO, break-even, real-world range, battery degradation).
- [x] Recommendation Engine with Decision Ratings, Risk Scores, and Explanation text.
- [x] FastAPI REST API with interactive Swagger documentation.
- [x] PostgreSQL persistence with SQLAlchemy 2 and Alembic.
- [x] Demo data seeds (Honda CR-V, Dacia Duster, Renault Zoe, MG4, Smart EQ).
- [x] Guided 7-step React frontend wizard with Recharts visualizations.
- [x] Docker & Docker Compose setup.

## v0.2 - Enhanced Analytics & Saved Comparisons
- [ ] Save and share analysis via custom link.
- [ ] Export analysis summary to PDF report.
- [ ] Advanced financing models (leasing with residual value balloon option).

## v0.3 - Vehicle Catalog & Live Imports
- [ ] Vehicle catalog import via public datasets.
- [ ] Live fuel and electricity price feeds.
- [ ] AutoScout24 / listing link auto-parser.

## v0.4 - AI Advisor Integration
- [ ] LLM-assisted decision explanation using structured calculation output.
